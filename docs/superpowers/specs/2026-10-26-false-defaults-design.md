# 启用字段策略中的布尔缺失默认值

状态：用户已确认启用字段策略中除鼻导管外、尚待实施的 11 个 `false` 默认值。

## 意图与边界

病历未提及的原始事实仍为 `value=null, mentioned=false, evidence=null`，不能伪造阴性证据。规则引擎使用 `ExtractedFacts.get()` 取得有效值：字段配置默认值时取默认值，否则继续穷尽相关条件的可能状态。明确提及的事实始终优先。仅修改字段注册表配置，不改分级公式、LLM 提取提示词、原始 JSON Schema 和输出格式。

## 选择

- 采用现有 `missing_default` 机制，启用字段策略表中待实施的 11 个 `false`：升压药、补液、精神状态改变、急性肾功能不全、癌症史、心衰史、慢性肺病、吸氧、面罩吸氧、无创及有创机械通气。原已启用的鼻导管默认值保持不变。
- 不把缺失事实改写成 `mentioned=true`；这会把没有病历证据的推断伪装为明确阴性。
- 不解析 Markdown 作为运行时配置；注册表仍是唯一可执行来源，字段策略供人工审核。

## 验收

上述 12 个字段缺失时有效值均为 `false`，明确 `true` 仍覆盖默认值；其他未配置默认值的缺失字段继续保留可能结果。全量测试与规范、字段策略一致。先前 `vasopressor_used` 的非法三元组错误不会因此自动合法化。
