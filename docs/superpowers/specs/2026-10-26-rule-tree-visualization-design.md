# 医生工作台规则判断树与可达路径设计

## 目的与范围

医生工作台的“规则流程概览”目前只按 A/E/D/C/B 列出结果标签，看不出条件、分支或一个等级从何而来。改为展示现行 2.2.0 规则的完整判断树，并根据当前结构化事实突出显示所有可达路径。医生选择某个结果及其具体路径时，可只查看这一条路径。这里的“可达”包括缺失事实允许的假设；不能把它称为已证实的病程或让页面重新诊断病历文本。

## 已考虑的办法

1. **仅前端展示规则树，按最终等级高亮叶子**：改动小，但 D2、D0 等有多个入口，无法准确指出经过的判断；不满足逐病例路径要求。
2. **前端再实现一套规则以推导路径**：表面上不改 Python 引擎，但会产生第二套临床规则，缺失值和共享字段很容易与正式分级不一致；不采用。
3. **在同一次确定性求值中附带记录路径，前端只负责展示**：沿用现有压缩枚举和共享字段语义，结果与路径由同一分支产生；采用此办法。

## 行为设计

- 页面改为全宽的“规则判断树”，放在病历、事实和结果区下方。树从 A 优先判断开始，依次包含 E2、低血压、低灌注、E1/D2、D1 候选与恢复后复发、PESI、C/B 子级，以及适用等级的 R 判断。D2 等多入口节点在树中分别出现，以保留真实父子关系；A、B、D0 的 `has_r=false` 直接标在结果叶子上。
- 每个判断展示条件和“是／否”（C 子级、血栓位置用对应的互斥分支标签）。所有节点始终可以查看；未命中部分使用低对比度，不从图中删除。
- 无结果时展示完整树、不高亮。分析或人工修订后，高亮与当前事实相容的全部分支及结果叶子。结果区可点击一个 `(grade, has_r)`；若该结果有多条可达路径，再选“路径 1/…”，单独高亮那条。恢复“全部结果”可重新查看所有可达分支。
- 路径上的分支分为“确定”和“可能”：在同一个前序判断序列下，该节点只有一个可达出口时为确定，用连续实线；仍有多个可达出口时为可能，用虚线。判断依据始终是完整路径集合，即使界面筛选到单条路径也不重新计算确定性。程序默认值产生的唯一出口归为确定，但图例须说明这是“按当前事实及默认值”。一条路径只要包含可能分支，整体就是可能路径；只有全部分支确定才是确定路径。
- UI 明示“高亮为与结构化事实相容的可能路径；缺失且无默认值时可能同时高亮互斥分支”，不把一条假设路径说成患者已实际经历的事实。证据仍在事实编辑区查看，本次不增加逐节点临床证据解释。
- 页面不依赖 CDN、Mermaid 在线渲染或新前端框架。用本地 HTML/CSS/JavaScript 生成可滚动、可键盘操作的树视图，手机上允许横向滚动，不挤压节点文字。

## 数据与接口

- 在规则层增加树结构定义和可达路径收集器；每条路径包含最终 `(grade, has_r)` 与按顺序记录的判断节点 ID、分支值。路径记录嵌入现有 `classify_possible` 的分支，而非从最终等级反推，也不枚举原始字段的全部排列。相同结果和相同判断序列去重，保留不同入口与不同 R 分支。
- 对所有去重后的路径，按“前序步骤 + 当前节点”分组统计可达出口；唯一出口标为确定，两个或更多出口标为可能。这是条件于前序路径的确定性，不是对未记录病历内容的医学推断。
- `medi.grading.classify(payload)`、命令行、工作流现有 JSON、`POST /api/classify` 和 `POST /api/reclassify` 的响应格式不变。新增只供工作台使用的 `GET /api/decision-tree` 和 `POST /api/decision-trace`；后者提交同一份完整事实 JSON，并返回结果与路径。网页在提取完成后用返回事实请求路径；事实修订时仅请求新接口，不调用 LLM。版本号防抖与过期响应保护沿用现有机制。
- 树定义与路径节点 ID 使用一套常量／校验，不允许页面自行推演规则。路径的每个分支必须能沿树从根走到与结果完全相同的叶子。若规则或树发生不一致，应由测试失败发现，不在 UI 静默展示错误路径。

## 边界与验收

- 不改变等级公式、默认值、字段 Schema、PESI/R 联合状态、结果排序或原有输出契约；只新增可选的可解释性接口。
- 测试覆盖 A 互斥、E2、D2 的两个入口、D1 复发排除、PESI 84/85 边界、B/C 子级、R 真/假、缺失字段产生多条路径及共享字段一致性；并验证唯一出口为确定、分叉出口为可能、筛选单条路径后不会把原本可能的分支误标为确定。对每条路径验证其可走通静态树且叶子与最终结果一致；路径结果集合必须等于现有分类结果集合。
- 页面测试检查判断节点、分支标签、选择器和语义提示；运行完整单元测试与 `git diff --check`。更新架构文档中“不返回路径”的限制，明确旧公开接口不变、新接口仅供本地工作台使用。
